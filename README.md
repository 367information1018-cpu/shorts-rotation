# 쇼츠 회전

PC 크롬에서 유튜브 쇼츠에 회전 버튼을 추가하는 확장 프로그램입니다. 옆으로 누워 재생되는 영상을 바로 돌려 가로로 넓게 볼 수 있습니다.

[설치용 ZIP v1.5.1](release/shorts-rotation-1.5.1.zip?raw=true) · [설정 화면](release/store-screenshot-1280x800.jpg) · [개인정보 처리방침 초안](release/privacy-policy-draft.txt)

## 설치

1. 위의 설치용 ZIP을 내려받고 압축을 풉니다. 저장소 전체를 내려받았다면 `extension` 폴더를 사용합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
4. 이미 열려 있는 유튜브 탭을 새로고침한 다음 쇼츠를 엽니다.

## 사용

쇼츠 영상 오른쪽 위의 회전 버튼으로 영상을 왼쪽 또는 오른쪽으로 90°씩 돌릴 수 있습니다. 가운데에 현재 각도가 표시되며, 각도를 누르면 업로드된 방향으로 돌아갑니다.

회전 창 왼쪽의 점 여섯 개를 잡고 드래그하면 페이지 안에서 위치를 옮길 수 있습니다. 같은 탭에서 다음 쇼츠로 넘겨도 옮긴 위치가 유지됩니다. 키보드로는 손잡이에 초점을 두고 방향키로 이동하거나 **Home** 키로 창을 영상 오른쪽 위에 다시 놓을 수 있습니다.

## 크롬 툴바 설정

크롬 툴바에서 **쇼츠 회전** 아이콘을 누르면 설정이 열립니다.

- **다음 쇼츠에도 회전 유지**를 켜면 같은 탭에서 쇼츠를 연속으로 넘길 때 현재 각도가 적용됩니다. 이 설정을 끄면 다음 쇼츠는 원래 방향에서 시작합니다.
- **쇼츠 회전 사용**을 끄면 열린 쇼츠에서 회전 창이 사라지고 영상이 원래 방향과 크기로 돌아갑니다. 다시 켜면 같은 위치에서 회전 창을 사용할 수 있습니다.
- **쇼츠 영상 크기**는 화면에 맞춘 영상 크기의 50%에서 200%까지 조절할 수 있습니다. 원래 방향과 회전한 상태 모두에서 영상 비율을 유지합니다. 확대된 영상이 플레이어보다 크면 가운데를 기준으로 가장자리가 잘립니다.
- **회전 창 크기**는 75%에서 150%까지 조절할 수 있습니다. 버튼과 각도 글씨가 함께 커지거나 작아집니다.

설정은 크롬에 저장됩니다. 새 탭에서 쇼츠를 열거나 페이지를 새로고침하면 영상의 시작 각도는 0°입니다.

이미 설치한 확장 프로그램을 업데이트하려면 `chrome://extensions`에서 **쇼츠 회전**의 새로고침 버튼을 누른 다음, 유튜브 탭을 새로고침합니다.
