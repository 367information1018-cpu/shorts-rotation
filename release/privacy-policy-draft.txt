쇼츠 회전 개인정보 처리방침

이 방침은 Chrome 확장 프로그램 쇼츠 회전 버전 1.5.1에 적용됩니다.

쇼츠 회전은 PC Chrome의 유튜브 쇼츠 페이지에서 영상에 회전 버튼을 표시하고 영상의 방향과 크기를 조절합니다. 이 기능을 위해 현재 페이지의 주소 경로와 플레이어의 영상 요소 및 화면 크기를 브라우저 안에서 확인합니다.

기능 사용 여부, 다음 쇼츠에서도 회전을 유지할지 여부, 영상 크기와 회전 창 크기 설정은 해당 브라우저의 Chrome 확장 프로그램 로컬 저장소에 저장됩니다. 사용자가 설정을 바꾸면 새 값으로 갱신되며, 확장 프로그램을 제거하면 확장 프로그램에 저장된 설정이 삭제됩니다.

확장 프로그램은 현재 페이지에서 확인한 정보와 저장한 설정을 개발자 서버나 제3자에게 전송하지 않습니다. 영상 파일을 다운로드하거나 별도 저장하지 않으며, 계정 등록을 요구하지 않습니다. 쇼츠 영상 재생은 유튜브 페이지에서 이루어집니다.

쇼츠 회전의 Chrome API를 통한 정보 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한적 사용 요건을 따릅니다. https://developer.chrome.com/docs/webstore/program-policies/limited-use

문의는 Chrome 웹 스토어의 쇼츠 회전 상세 페이지에 표시된 게시자 연락처로 보내 주세요.
